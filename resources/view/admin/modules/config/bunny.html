Credenciais Bunny desta escola —

Cada escola usa a própria conta Bunny.net. As chaves ficam criptografadas e nunca vão para o portal do aluno. Sem Bunny ativo, o editor EAD continua só com YouTube.

Em Stream → Library → CDN / hostname (sem https://).
Deixe em branco para manter a chave já salva.
Library → Security → Token authentication. Deixe em branco para manter.
Checklist de segurança (painel Bunny)
  1. Ativar Token Authentication na Video Library.
  2. Ativar Block Direct URL File Access.
  3. Em Allowed Domains / Allowed Referrers, cadastre: admin.ctieducacional.com.br (painel) e aluno.ctieducacional.com.br (portal do aluno).
  4. Use a Token Authentication Key da área Security da library (não use a API AccessKey).
  5. Se o plano Bunny permitir, ative MediaCage DRM (protege contra download).
  6. No player, desative velocidades extras de reprodução (o portal do aluno também bloqueia acelerar e pular o vídeo).
