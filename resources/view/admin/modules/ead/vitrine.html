Este recurso ainda não está liberado nesta escola. Fale com o suporte para ativar.

Onde fica: menu Portal EAD → Vitrine de cursos (também pelo botão na lista de Cursos Online).

Para aparecer aqui: a outra escola precisa marcar o curso como Publicado + Disponibilizar na vitrine (pago ou gratuito).

Antes de assinar, use Ver amostra (1º vídeo, PDFs e tópicos). Para material completo, fale com a escola dona e peça uma demonstração.

Assine cursos de outras escolas (licença). Seus alunos usam o conteúdo original. Cursos pagos entram na fatura SaaS; gratuitos não cobram o preço do criador (taxa CTI só se o suporte configurar).
